The name of this data structure suggest list are linked.

Here list reffer to an node an node contain 2 part data and pointer.

The data part store the value and the pointer part store the address of next node  address reffer to the memmoery location.

Unlike array linked list are non cotigious , dynamic and can store heterogeneous data types.

In linked list the starting node is called head and ending node is called tail.

In tail node the pointer is always null. Since it is the last element there will be no node after that to store its address in the tail node pointer.
